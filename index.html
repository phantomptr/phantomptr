PS5Upload

Desktop · Mobile · Browser

Send games, apps and homebrew to a jailbroken PS5, and manage the console from your computer, phone or browser. Fast encrypted transfers, package installs, game images, save backups and a collection of every game you own. For macOS, Windows, Linux, Android and Docker.

AVA1

Rust · C

A fast, encrypted, resumable file-transfer protocol, designed for sending files to a PS5 and built for any two devices: parallel lanes that adapt to whatever is slowest, pick-up-where-it-stopped resume, and every file verified with BLAKE3. A written spec, test vectors, and matching Rust and C implementations. It carries every transfer in PS5Upload.
